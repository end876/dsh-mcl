# 自定义背景

MCL 1.0 的界面支持换背景：可以不放图（用主题自带的底），也可以传一张自己的图片，
再用四套「背景样式」和四个滑杆把它调到好看又看得清。

> 背景图**只存在本机**，不会上传到任何服务器。换电脑 / 重装不会自动带走。

## 1. 在哪里设置

打开浏览器界面（`mcl gui` 或独立窗口），左侧导航 → **外观**：

- **主题**：A 深海玻璃 / B 像素方块 / C 极简白（默认）
- **背景图**：`无背景`（只关掉显示，图还留着） / `上传图片` / `使用背景`（关掉后恢复） / `移除`（删文件）
- **背景样式**：亮雾 / 深海 / 渐变 / 暗玻璃
- **滑杆**：模糊、压暗、玻璃不透明度、焦点位置
- **恢复默认**：把样式和滑杆恢复成默认值（不动图片）

主题决定 UI 的材质（圆角、边框、字体、强调色）；背景是独立一层，两者可以自由组合。
像素风（B）遇到背景时会强制实底——像素边框叠在照片上会非常乱。

## 2. 支持的图片

| 项目 | 说明 |
| --- | --- |
| 格式 | jpg / jpeg / png / webp / gif（gif 只取第一帧） |
| 上传上限 | 16 MB（服务端拒绝更大的） |
| 自动压缩 | 浏览器端先按最长边 2560px 缩放，再编码成 JPEG（质量 0.9） |
| 存放位置 | `~/.mcl/ui/background.<扩展名>` |
| 横竖构图 | 用「位置」滑杆调焦点（0 = 顶部，100 = 底部）；竖图建议配合「深海」或「渐变」 |

> 大图（手机原图 10MB+）传上去会自动压到 2560px、通常只剩几百 KB，不会拖慢界面。

## 3. 四套背景样式

| 预设 | 蒙版 | 玻璃 | 适合 |
| --- | --- | --- | --- |
| **亮雾** | 白色蒙版 ~30% | 白玻璃 66% | 亮色、浅色图；字用深色，氛围柔和 |
| **深海** | 深蓝蒙版 ~42% | 青色玻璃 42% | 深色图 / 想保留主题的青色玻璃感 |
| **渐变** | 左侧 96% → 右侧 18% 的方向渐变 | 深玻璃 60% | 人物图、风景图：左边放文字，右边透出图 |
| **暗玻璃** | 均匀深色蒙版 ~52% | 深玻璃 58% | 可读性优先，任何图都能用 |

每个预设有自己的默认滑杆值；点预设会重置滑杆，再拖滑杆就进入自定义。

## 4. 四个滑杆

| 滑杆 | 范围 | 作用 | 调大会怎样 |
| --- | --- | --- | --- |
| 模糊 | 0 – 30 px | 背景图的模糊程度 | 更柔和，图更不可辨认 |
| 压暗 | 0 – 80 | 蒙版不透明度 | 文字更清楚，图更暗（亮雾下是“白得更狠”） |
| 玻璃 | 30 – 95 | 卡片/面板的不透明度 | 卡更实、更好读，图更少透出来 |
| 位置 | 0 – 100 | 背景图的垂直焦点 | 想让人脸/主体露出来时调它 |

可读性建议：

- 文字所在的区域（左侧/上方）至少留 40% 压暗，或把玻璃拉到 60% 以上
- 亮雾适合浅色图，但亮图 + 白玻璃会「糊成一片」，适当降低玻璃或提高压暗
- 竖图整屏铺会裁掉一部分，用「位置」把脸放到卡片之间的空隙里

## 5. 配置文件

`~/.mcl/ui/appearance.json`：

```json
{
  "theme": "minimal",
  "preset": "dark",
  "blur": 8,
  "dim": 35,
  "glass": 62,
  "pos": 30,
  "bgFile": "background.jpg",
  "bgMime": "image/jpeg",
  "bgVersion": "2db47c464412",
  "bgEnabled": true
}
```

- `theme`：`minimal` / `deepsea` / `pixel`
- `preset`：`light-fog` / `deepsea` / `gradient` / `dark`
- `bgEnabled=false`：保留图片但暂时不用
- 删掉这个文件等于恢复默认外观

## 6. HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/ui/appearance` | 读取外观配置（含 `hasBg` / `hasFile`） |
| `POST` | `/api/ui/appearance` | 改主题 / 预设 / 滑杆 / `bgEnabled` |
| `GET` | `/api/ui/background` | 取背景图（无图返回 404） |
| `POST` | `/api/ui/background` | 上传图片，`Content-Type: image/*`，原始二进制 |
| `DELETE` | `/api/ui/background` | 删除背景图 |

`POST /api/ui/appearance` 允许的字段：`theme`、`preset`、`blur`、`dim`、`glass`、`pos`、`bgEnabled`。
越界值会被夹到合法范围，未知字段忽略。

## 7. 常见问题

**传了图但界面没变？**
看「背景图」那一行的按钮：如果显示「使用背景」，说明图在但被关掉了，点一下；
还不行就刷新页面（外观配置在打开页面时读取）。

**背景太糊 / 字看不清？**
优先降「模糊」、加「压暗」；或换「暗玻璃」预设。

**上传失败？**
- 确认格式是 jpg/png/webp/gif
- 超过 16MB 会失败，先自己压一下
- 看启动器日志（`mcl gui` 的终端）有没有 400/415

**换主题会丢背景吗？**
不会。主题和背景是两套配置，互不覆盖。

**背景图会被打包进 release 吗？**
不会。图片在 `~/.mcl/ui/`（用户目录），发布包里没有任何用户图片。
